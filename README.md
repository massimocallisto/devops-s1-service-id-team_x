## Contributi
1. Crea un branch di sviluppo:
   ```bash
   git checkout -b feature/<nome-feature>
   ```
2. Effettua le modifiche e il commit:
   ```bash
   git commit -m "Aggiunge nuova funzionalità"
   ```
3. Esegui il push e apri una Pull Request su GitHub.
