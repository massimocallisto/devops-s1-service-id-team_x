# Profilo – Massimo Callisto

## Sommario
Ricercatore universitario che guida progetti di ricerca su soluzioni IoT, integra pipeline DevOps nei laboratori e cura architetture di sistema scalabili per ambienti accademici e industriali.

## Competenze ed Esperienze
- Linguaggi di programmazione: focalizzato su linguaggi orientati ai sistemi, con particolare attenzione a Python per prototipazione IoT e automazione.
- Strumenti e piattaforme: pipeline CI/CD, containerizzazione, infrastrutture cloud e tool di osservabilità per ambienti DevOps.
- Aree di interesse: architetture di sistema distribuite, edge computing IoT e gestione del ciclo di vita delle applicazioni.
